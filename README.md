# Valokuvien jako applikaation

## Käyttäjä toimminnot

Julkaise valokuvia sivulle<br>
Anna valokuvallesi tiedot ja tarina<br>
Valtse kaegoria johon voit tallentaa valokuviasi<br>
Kommentoi toisten kuvia<br>
Etsi kuvia nimen, sijannin, tarinan sisällön tai muun katergorina mukaan<br>
Näe tilastoja kuvista ja käyttäjistä<br>
Tutki omaasi ja toisten profiileja<br>
Applikaatiosta löytyy tilastoa statistics sivulta ja mini version tästä on löydettävistä
 käytäjän omalta sivulta<br>
## Ylläpitäjän oikeudet ja toimminnnot

# Applikaation testaus

Luo tarvittava tietokanta kommenolla sqlite3 database.db, database.db < schema.sql ja database.db < init.sql<br>
Luo käyttäjä klikkaamall signin linkkiä navigointi valikossa<br>
Kirjaudu sisään luomalle käyttäjällesi login linkin kautta<br>
Lisää .jpg ja -png formaattisia kuvia ja niemä kuvat anna niille kuvaus ja päivämäärä<br>
Kuvan voi lisätä neljän(toistaiseksi) eri kategorian alle<br>
Voit katsoa käyttäjän omat kuvat my pictures linkistä<br>
Myös tekemäsi kommentit löytyvät my commets linkistä<br>
voit etsiä kuvia antamalla avain sanan, kuvien hakeminen perustuu nimiin ja kuvauksiin<br>
Kuvia voi myös etsiä eri kategorioista<br>
voit muokata kuvan nimeä, kuvausta tai päivämäärää modify napulan kautta<br>
Voit poistaa kuvan delete napin avulla<br>
kirjaudu ulos painamalla logout linkkiä<br>
Voit katsoa kuvia joita applikaatioon on lisätty ilman että kirjaudut sisään<br>

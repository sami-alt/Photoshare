## Ylläpitäjän oikeudet ja toimminnnot

# Applikaation testaus

Luo tarvittava tietokanta kommenolla sqlite3 database.db && database.db < schema.sql<br>
Luo käyttäjä klikkaamall signin linkkiä navigointi valikossa<br>
Kirjaudu sisään luomalle käyttäjällesi login linkin kautta<br>
Lisää .jpg formaattisia kuvia ja niemä kuvat anna niille kuvaus ja päivämäärä<br>
Voit katsoa käyttäjän omat kuvat my pictures linkistä<br>
voit etsiä kuvia antamalla avain sanan, kuvien hakeminen perustuu nimiin ja kuvauksiin<br>
voit muokata kuvan nimeä, kuvausta tai päivämäärää modify napulan kautta<br>
Voit poistaa kuvan delete napin avulla<br>
kirjaudu ulos painamalla logout linkkiä<br>
Voit katsoa kuvia joita applikaatioon on lisätty ilman että kirjaudut sisään<br>
